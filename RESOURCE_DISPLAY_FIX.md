## 📊 **Resource Sources**

The system now checks for resources in this order:

1. **API Response** (`data.resources`)
   - Resources stored in TopicResource model
   - Generated by AI or added manually

2. **Topic Data** (`topic.resources`)
   - Resources embedded in roadmap JSON
   - From LLM generation or fallback

3. **Fallback Message**
   - If neither above exists
   - Provides helpful suggestions
